## (a) Root Cause of the "Reset" — Lost Dictionary and Snippets

### Conclusion

**The files are NOT lost and NOT empty. They contain Hamed's full custom entries.**

- `dictionary.json` — 17 terms + 17 substitutions (all Hamed's, e.g. "see lux" → "Silux", "cloud" → "claude", etc.)
- `snippets.json` — 17 custom cues including calendar links, academy pitch, email sign-offs, address.

Both files exist on disk at the repo root and contain exactly the custom data Hamed built.

### Why Hamed thought they "reset"

**Severity: MED. Effort: S.**

Three plausible causes:

1. **`.gitignore` excludes the live files.** `dictionary.json` and `snippets.json` are explicitly listed in `.gitignore` (lines 13–14). If Hamed ran `git clone` or `git checkout` on another machine, or pulled into a clean working tree, both files would NOT be restored. They exist only on the machine where he created them. This is the most probable cause of a "fresh install feels like a reset" experience.

2. **`_ensure_user_config` in `main.py` (lines 172–183) seeds from the example.** This function is called every time the tray opens the editor (`_on_edit_dictionary`, `_on_edit_snippets`). If `dictionary.json` does NOT exist, it copies `dictionary.json.example` over it and logs `"Seeded from example"`. On a fresh clone (where the file is gitignored), the first editor open would create an example-content file, silently discarding whatever the user expected to find. This is benign in practice today (because the live files exist), but becomes destructive after any `git clean -f` or a fresh clone.

3. **`dictionary.py._source()` silently falls back to the example** (line 36) if `dictionary.json` is absent. The app runs, Whisper gets no custom bias, substitutions don't fire — it *behaves* as if the dictionary is empty even though the user's data was never overwritten.

### Is it recoverable from git history?

**No.** `git log -- dictionary.json snippets.json` returns no output. Both files are in `.gitignore` and were never committed. `git show <any-commit>:dictionary.json` returns `fatal: path 'dictionary.json' exists on disk, but not in '<commit>'`.

**Recoverable: NO** from git. The only copy is the live file on disk.

**Recovery command:** Not applicable. The files exist and contain the correct data right now. If a future clean clone loses them, Hamed must copy both files to a safe location manually before any `git clean` or clone operation.

### The real risk going forward (HIGH severity)

The gitignore design is intentional (avoids committing private data), but there is no backup mechanism. If the drive is wiped or the repo is re-cloned, both files are gone. The README documents "copy from .example" as the setup step, which implies user customisation is not persisted anywhere except the local filesystem.

## (b) Full Feature and Architecture Map

### Data flow summary

```
[Alt+1 hold] -> recorder.py (sounddevice WAV capture, tempfile)
    -> main.py _dispatch()
        -> transcribe.py (Groq Whisper, verbose_json, segment filter, tail trim, substitutions)
        -> main.py (voice-command check, capture-command check, snippet check)
        -> cleanup.py (Groq llama-3.3-70b-versatile, prompts/*.txt, fallback=raw)
        -> paste.py (pyperclip + Ctrl+V)
        -> history.py (logs/YYYY-MM-DD.jsonl append)
[Alt+1 double-tap] -> vad.py SessionManager (webrtcvad, chunked bursts)
[overlay click] -> overlay.py mode/translate/position -> .overlay-state.json
[tray menu] -> tray.py -> main.py callbacks
[editor open] -> dictionary_editor.py / snippets_editor.py -> CTk table UI
                -> dictionary.py save_substitutions() / snippets.py save_snippets()
```

### Module inventory

| Module | Purpose |
|---|---|
| `main.py` | Entry point. Hotkey hooks (keyboard lib), dispatch loop, session mode, voice-command/capture-command/snippet routing, inline-formatting split. |
| `recorder.py` | sounddevice InputStream. Accumulates int16 frames while Alt+1 held. Writes WAV tempfile on release; drops clips < 250ms. |
| `vad.py` | `SessionManager`: webrtcvad continuous capture. Chunks speech bursts by VAD silence. Calls `on_burst(wav_path)` per burst. Gated by `is_available()`. |
| `transcribe.py` | Groq Whisper-large-v3 via multipart POST. Returns `(text, language)`. Guards: `no_speech_prob` ceiling, per-segment filter, `_trim_hallucination_tail()`, `_is_hallucination()`. Applies dictionary substitutions. |
| `cleanup.py` | Groq llama-3.3-70b-versatile cleanup. Loads mode prompt from `prompts/`. REWRITER_GUARD prefix. Translate suffix. Timeout scales with transcript length. Falls back to raw (or empty for >120 chars) on error. |
| `router.py` | `pick_mode()`: reads `settings.router_rules` (process name + window title). First match wins; default `polished`. |
| `dictionary.py` | Loads `dictionary.json` (falls back to `.example`). mtime cache. `get_terms_prompt()` for Whisper prompt bias. `apply_substitutions()` regex whole-word replace. `save_substitutions()` atomic write. |
| `snippets.py` | Loads `snippets.json` (falls back to `.example`). mtime cache. `expand_snippet()` exact-cue match (normalised). `save_snippets()` atomic write. |
| `settings.py` | Single-source-of-truth config. Loads `settings.json` over frozen dataclass defaults. Covers hotkeys, VAD params, Whisper/cleanup model and timeouts, router rules, voice commands, inline formatting, capture commands. Module-level singleton. |
| `config.py` | `load_config()`: reads `GROQ_API_KEY` from `.env` via python-dotenv. Exits on missing key. |
| `paste.py` | `paste_text()`: pyperclip.copy + keyboard.send Ctrl+V. |
| `history.py` | Appends JSONL records to `logs/YYYY-MM-DD.jsonl`. `last_ten()` reads back recent records. |
| `overlay.py` | CTk floating gadget. State LED, equaliser, language pill, mode pill (dropdown), translate toggle, session toggle, hide. Persists position + forced_mode + translate_to_english to `.overlay-state.json`. |
| `tray.py` | pystray system tray icon. Menu: pause, force mode, edit dictionary/snippets, view logs, hide/show gadget, quit. |
| `dictionary_editor.py` | CTk table UI for dictionary.json substitutions. Reads via `dictionary.load_substitutions()`, writes via `dictionary.save_substitutions()`. |
| `snippets_editor.py` | CTk table UI for snippets.json. Multi-line expansion column. Reads/writes via `snippets.load_snippets()` / `snippets.save_snippets()`. |
| `prompts/*.txt` | Mode-specific cleanup instructions (5 files: polished, brand_voice, prompt, note, raw). |
| `_smoke_substitutions.py` | Offline unit tests for substitutions, snippets, hallucination filter. |

### Hotkeys

| Gesture | Behaviour |
|---|---|
| Hold `Alt+1` | Hold-to-talk record |
| Double-tap `Alt+1` | Toggle session (VAD) mode |
| Click mode pill | Open mode/translate/quit dropdown |
| Drag grip bar | Move gadget; position auto-saved |
| Pause icon | Pause/resume |

### Session mode

Double-tap `Alt+1`. VAD (`webrtcvad`) chunks continuous mic into bursts. Each burst dispatched through the same `_dispatch()` path as hold-to-talk. Bursts are serialised via a `queue.Queue` and a single worker thread to prevent clipboard races.

### Translate toggle

Overlay dropdown sets `_translate_to_english` flag. Persisted to `.overlay-state.json`. When on: `TRANSLATE_SUFFIX` appended to cleanup prompt; timeout extends from 2.0s to 3.5s; dictionary substitutions are skipped after cleanup (to avoid clobbering the translated output).

## (c) The Five Cleanup Modes

All prompts live in `prompts/*.txt`. All share an identical preamble block (British English, no em-dash, banned phrases, no invented facts, Persian passthrough, output-only). The `REWRITER_GUARD` in `cleanup.py` (lines 35–55) prepends to every mode prompt.

| Mode | File | Rating | Notes |
|---|---|---|---|
| `polished` | `prompts/polished.txt` | **Solid** | Full instructions: fix fillers/false starts/grammar, add sentence boundaries, preserve speaker voice/rhythm. Well-scoped. |
| `brand_voice` | `prompts/brand_voice.txt` | **Solid** | Good brand rules: short sentences, specific nouns, BLUF, anti-fluff. Hardcodes "Maker's AI Lab or Silux London" — will not generalise if shared. MED severity. |
| `prompt` | `prompts/prompt.txt` | **Solid** | Structured Goal/Constraints/Output-Shape format. Terse. No known weaknesses. |
| `note` | `prompts/note.txt` | **Thin** | Correct intent (light touch) but gives the model very little to distinguish from `polished` on non-obvious inputs. No examples. LOW severity. |
| `raw` | `prompts/raw.txt` | **Thin** | Instructed to fix only transcription errors and leave everything else. Risk: the model may still make style improvements (LLMs are biased toward polished output); there is no enforcement of "do not change filler words" beyond the instruction. LOW severity. |

### Weaknesses flagged

**brand_voice: hardcoded brand names (MED/S).**  
`prompts/brand_voice.txt` line 10 names "Maker's AI Lab or Silux London". If this repo is shared or used on a different project, brand_voice mode would produce mismatched output. The brand should be read from a config file or the instruction should be generic.

**note + raw: no output-similarity guard (MED/M).**  
Both modes ask for "minimal" changes. In practice the model may still rewrite substantially (especially on short inputs). There is no post-cleanup comparison that detects over-editing. See section (d).

**prompt: no fallback structure (LOW/S).**  
If the speaker gives a very short, context-free utterance (e.g. "write a blog post"), the structured output will be skeletal. Consider adding a "minimum viable output" instruction for thin inputs.

## (d) Garbage-Output Failure Modes

### In `transcribe.py`

**`_is_hallucination()`** (lines 37–89): conservative by design. Catches single known-noise tokens, 3-in-a-row repeats, and pure ABAB loops. Does NOT catch:
- Short known-noise tokens appearing mid-sentence.
- Novel phantom proper nouns not yet in `_NOISE_PATTERNS`.
- Tail loops shorter than 3 repetitions.

**`_filter_segments()`** (lines 114–145): drops individual segments by `no_speech_prob`, `compression_ratio`, or `avg_logprob`. Thresholds are configurable via `settings.json`. Risk: over-aggressive thresholds silently delete valid speech. Under-aggressive thresholds let hallucinated segments through.

**`_trim_hallucination_tail()`** (lines 148–218): token-level trailing-repeat trim + sentence-terminator fallback. Requires run >= 2 and token length > 2. Will not catch single-occurrence phantom tokens at the end (e.g. "please send me an email Sepehr" where "Sepehr" is phantom).

**Quality guard gap:** There is NO comparison of cleaned output against the raw transcript. If cleanup returns something radically different (hallucinated insertion by the LLM, wrong language, completely rewritten content), it is pasted unconditionally. The exact function where a quality gate should slot in is `cleanup.clean()` at line 141, after the `content` string is produced:

```python
# Proposed insertion point (cleanup.py, line 141, after content is built):
if _divergence_score(transcript, content) > THRESHOLD:
    log.warning("Cleanup divergence too high, using raw transcript")
    return transcript.strip(), True
```

A simple implementation: normalised edit distance or length ratio (if cleaned is 3x+ longer than raw, or shares fewer than 40% of the raw tokens, treat as divergent and fall back).

**In `cleanup.py`**

**Fallback threshold (lines 149–155):** Transcripts > 120 characters fall back to empty string on cleanup failure (not raw transcript). This is intentional (Whisper long-transcript garbage is worse than nothing). But 120 chars is low: a 2–3 sentence dictation may be 150–200 chars. Any Groq timeout on a medium-length dictation produces silent failure (nothing pasted). The user gets no toast and has to re-dictate.

**Severity: MED.** The existing `fallback: true` flag in the JSONL log is the only diagnostic.

**Quote stripping (lines 138–140):** strips one layer of surrounding quotes. Does not strip nested quoting. Does not handle the case where the model wraps in triple backticks (possible for `raw` mode output that looks like code).

**In `router.py`**

No failure mode that produces garbage. Worst case is misrouted mode (e.g. wrong window detected due to pywin32 returning stale foreground). This is silent: the user gets polished output instead of brand_voice, etc.

**Session mode clipboard race (mitigated).**  
`_session_dispatch_queue` serialises bursts. If the worker thread crashes mid-dispatch (unhandled exception), the queue fills up silently. The `_session_worker_loop` catches exceptions per burst but does not restart the worker if the thread itself dies. Severity: LOW (thread death is rare).

## (e) Distribution Readiness

### Runtime dependencies (`requirements.txt`)

| Package | Purpose | Blocks non-technical users? |
|---|---|---|
| `sounddevice` | Mic capture | Requires PortAudio system library (`pip` installs it on Windows usually, but sometimes fails silently) |
| `soundfile` | WAV I/O | No issues |
| `requests` | HTTP to Groq | No issues |
| `keyboard` | Global hotkey hooks | **Admin rights required** (UAC elevation). This is the #1 install blocker. README documents it. |
| `pyperclip` | Clipboard | Requires `xclip`/`xsel` on Linux; fine on Windows |
| `pywin32` | Window detection | Post-install step required: `python Scripts\pywin32_postinstall.py -install`. README mentions it. |
| `psutil` | Process name lookup | No issues |
| `pystray` | Tray icon | Needs a display; fails in non-interactive sessions |
| `Pillow` | Tray icon image | No issues |
| `customtkinter` | Overlay + editors | No issues |
| `webrtcvad-wheels` | Session mode VAD | Optional but required for session mode. Falls back gracefully with a toast. |

**No model downloads required.** Both Whisper and llama-3.3-70b are Groq-hosted APIs.

**`python-dotenv` is NOT in `requirements.txt` (MED/S).** `config.py` imports it with a graceful fallback, but the fallback silently relies on the OS environment having `GROQ_API_KEY` set, which will not be the case for a fresh user following only the README. The README says `copy .env.example .env` but nothing installs `python-dotenv` unless the user adds it.

### API key requirement

GROQ_API_KEY must be in `.env` at the repo root. `config.py` exits with a clear error if missing. `.env` is listed in `.gitignore` (line 2). `.env.example` is NOT in the repo file listing from the glob — confirmed absent. **The README references `copy .env.example .env` but `.env.example` does not exist in the repository.** Severity: HIGH for new users.

### Admin rights

The `keyboard` library requires elevation. README documents this. Not automatable without a setup script or UAC manifest.

### `.gitignore` coverage

- `.env` excluded (correct).
- `dictionary.json` and `snippets.json` excluded (correct for privacy, but means user data is never backed up).
- `.overlay-state.json` excluded (correct — machine-local position/state).
- `logs/` excluded (correct).
- `__pycache__/` excluded (correct).
